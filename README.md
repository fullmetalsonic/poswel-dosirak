# 포스웰 도시락 예약

한국 달력과 근무표를 바탕으로 포스웰 도시락 신청을 예약하는 Android 앱입니다. **포스웰 또는 관련 회사가 제작·운영·보증하는 공식 앱이 아니며, 해당 회사와 제휴한 앱도 아닙니다.** 사이트명은 연결 대상 서비스를 설명하기 위해 사용합니다. 도시락·달력 아이콘은 별도로 생성한 이미지이며 공식 로고가 아닙니다.

## 설치와 버전

Android 8.0 이상에서 사용합니다. [최신 정식 배포판](https://github.com/fullmetalsonic/poswel-dosirak/releases/latest)에서 APK를 받고, SHA-256과 검증 범위를 릴리스 설명과 대조하세요. `-test`가 붙은 과거 개발용 시험판이 아니라 정식 서명 APK를 선택합니다. 여기서 정식 배포판은 이 프로젝트의 안정 배포판을 뜻하며 포스웰의 공식 앱이라는 뜻이 아닙니다.

기존 개발용 앱은 서명이 달라 정식 APK로 덮어 설치할 수 없습니다. **자동주문 OFF → 계획 백업 저장 확인 → 사이트 실제 주문내역 확인 → 본인 판단으로 기존 앱 삭제 → 정식 설치·백업 가져오기 → 재로그인·근무표·권한·새 구매 동의 확인 → 자동주문 ON** 순서로 전환합니다. 전송 여부가 불명확한 주문이 있으면 삭제·전환을 보류하세요. 백업에는 설정·날짜별 예외만 포함되며 계정·쿠키·실행 원장은 옮겨지지 않습니다. 자세한 절차는 [서명 전환 안내](MIGRATION.md)를 따릅니다. 전환 후 같은 정식 키의 후속 업데이트는 앱을 삭제하지 않고 설치합니다.

버전의 기준은 [앱 빌드 설정](android-app/app/build.gradle.kts)의 `versionName`과 `versionCode`입니다. 설치된 버전은 앱의 `설정 → 앱 정보`에서 확인합니다. 이 문서에는 별도의 고정 버전 번호를 관리하지 않습니다.

## 처음 설정

1. `설정 → 계정`에서 계정을 저장하고 로그인 상태를 확인합니다. 사이트 탭에서 배송지를 등록·확인합니다. 외부 브라우저의 로그인 상태는 자동 공유하지 않습니다.
2. 근무 유형과 기준일을 설정하고 달력의 주간·야간·휴무가 실제 근무표와 맞는지 확인합니다. 자동 계획은 선택한 주간 일정에 적용하며, 날짜별 휴가 제외·대근·지원은 달력에서 변경합니다.
3. 수량, 신청 시각과 금액 한도를 저장합니다. 신청 시각은 한국시간 `06:00:00~07:59:59`입니다. 금액 한도를 사용할 때는 개당 한도와 1회 총액 한도를 모두 입력합니다.
4. 정확 알람, 알림과 배터리 제한 상태를 확인합니다. 자동실행 설정에서 배터리 제한 해제를 허용하면 신청 2분 전 준비를 사용할 수 있습니다. 제조사 절전과 네트워크 제한도 확인합니다.
5. 설정 목록의 `자동주문`을 켜고 규칙·다음 신청·실제 구매 동의를 확인합니다. 기본값은 OFF이며 계정 변경·삭제 시에도 실제구매 예약은 해제됩니다.

설정 입력은 저장 전까지 초안입니다. 날짜별 예약 취소는 앱의 신청 계획을 제외하는 동작이며, 사이트에 이미 완료된 주문을 취소하지 않습니다. 자동주문 끄기는 즉시 적용되지만 이미 전송된 요청이나 완료된 주문을 되돌리지는 않습니다.

## 실행과 한계

앱은 사이트의 구조화된 필드로 로그인·임시 주문·최종 신청·주문내역 대조를 수행합니다. 제출 가능성이 있거나 결과가 불명확한 주문은 자동 재제출하지 않고 내역 확인을 우선합니다. 동일 계정은 한 기기에서만 자동 실행하는 것을 권장합니다.

서버 시각과 당일 메뉴를 확인한 뒤 신청하며, 사전 준비는 정확 알람·배터리 예외와 네트워크 상태의 영향을 받습니다. 강제중지, 첫 잠금 해제 전, 제조사 절전과 사이트 변경에 따른 실행 성공을 보장하지 않습니다. 한 번의 실제 주문 성공은 다른 기기·Doze·재부팅·네트워크 장애 조합의 검증을 대신하지 않습니다. 각 릴리스의 실제 검증 범위를 확인하세요.

금액 한도는 **제출 전 사이트 표시 금액**을 기준으로 검사합니다. 서버가 최종 공제액을 고정한다는 보장은 없으며, 조회와 제출 사이 가격 변경 위험에 대한 동의가 필요합니다. 화면 꺼짐 미디어 재생·전역 음량 변경은 지원하지 않습니다. 결과 알림은 Android의 알림 채널·음량·방해금지 설정을 따릅니다.

앱은 이용자의 정당한 계정과 사이트 이용 권한을 전제로 합니다. 사이트의 이용약관·개인정보 처리방침·자동화 허용 여부는 사이트 운영자의 기준을 따라야 합니다. 앱 배포나 소스 공개가 사이트 운영자의 자동화 허가를 뜻하지 않습니다.
