# 포스웰 도시락 예약

한국 달력과 근무표를 기반으로 포스웰 도시락 신청을 예약하는 개인용 Android 앱입니다.

## 설치

GitHub에 로그인한 상태에서 [릴리스](https://github.com/fullmetalsonic/poswel-dosirak/releases)의 Assets 중 `poswel-dosirak-0.1.1-test.apk`를 다운로드합니다. Android 8.0 이상을 대상으로 하는 개발용 버전입니다. 기기의 다운로드/설치 정책에 따라 해당 브라우저의 앱 설치 허용이 필요할 수 있습니다.

## 설정

1. 계정을 저장합니다. 로그인 확인과 사이트 탭의 배송지 최초 등록을 권장합니다.
2. 근무 유형을 선택하고 미리보기의 주간/야간/휴무가 실제 근무표와 일치하는지 확인합니다.
3. 기본 수량과 자동주문 시각을 입력합니다. 금액 한도는 선택이며, 사용할 때는 도시락 1개 최대금액과 한 번에 주문할 최대금액을 모두 입력합니다.
4. 휴대폰 설정에서 정확 알람, 알림, 배터리/데이터 제한의 현재 상태를 확인합니다.
5. 다음 계획과 설정을 확인하고 `자동주문 시작`을 누릅니다. 열리는 동의창에서 체크한 뒤 `동의하고 자동주문 시작`을 누르면 같은 설정을 저장하고 예약합니다.

날짜별 수량, 휴가 제외와 대근/지원 예약은 달력에서 날짜를 선택합니다. 설정 입력값은 탭 이동이나 상태 갱신으로 지워지지 않으며 `설정만 저장`으로 자동주문을 켜지 않고 보관할 수 있습니다. 재시도 등은 고급 설정에 있습니다.

기본 자동실행은 OFF입니다. 최초 활성화부터 반복 구매를 선택할 수 있습니다. 앱에서 계획을 제외해도 이미 사이트에 완료된 주문은 취소되지 않습니다. 동일 계정은 하나의 기기에서만 자동실행하는 것을 권장합니다.

## 구현과 검증

달력·사이트·설정 3탭, 7가지 근무 유형, 날짜별 예외, 공유 WebView 세션과 저장 계정 로그인, 실제 주문 통신, 주문내역 대조, 영속 실행 기록, OS 알람과 미래 일정 복원을 구현했습니다. 버튼 좌표가 아니라 사이트의 구조화된 필드/응답을 사용합니다.

JVM 적용 시험 135개, Android 가상 기기 UI 24개 및 저장소 7개 시험이 통과했습니다. 초기 시험의 공휴일 기대값과 중복 UI 선택자를 수정한 후 관련 시험을 재검증하고 변경 없는 통과 근거를 재사용했습니다. lint 오류 0 및 최종 APK 빌드를 확인했습니다.

**실제 휴대폰의 잠금/Doze·재부팅·정각 알람·소리/진동과 앱을 통한 실제 구매는 아직 검증 전입니다.** 서버의 최종 가격 고정은 확인되지 않아 표시금액 한도가 실제 공제액을 엄격히 보장하지 않습니다. 화면 꺼짐 미디어 경보는 미지원입니다. 강제중지/제조사 절전/첫 잠금 해제 전에는 실행을 보장하지 않습니다.

실제 계정정보, 쿠키, 배송지, 주문자료, 서명키 및 로컬 시험 로그는 이 저장소에 포함하지 않습니다. 사이트 fixture의 계정/배송값은 모의 자료입니다.

## 빌드

Android SDK 및 JDK 설정 후 `android-app`에서 실행합니다.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

현재 버전은 `0.1.1-test`, 패키지는 `com.fullmetalsonic.dosirak`입니다. 릴리스 APK는 개발용 디버그 서명입니다.
