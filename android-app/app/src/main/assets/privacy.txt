# 개인정보 처리 설명

기준일: 2026-10-09. 이 문서는 앱 코드의 처리 범위를 설명합니다. 포스웰의 공식 개인정보 처리방침이 아니며, 본 앱은 포스웰 또는 관련 회사와 제휴·연계하여 운영하는 공식 앱이 아닙니다.

## 기기에 저장하는 정보

| 항목 | 목적과 저장 방식 |
| --- | --- |
| 사용자가 저장한 사이트 아이디·비밀번호 | 로그인 복구와 예약 신청에 사용합니다. AndroidKeyStore의 기기 내 AES 키와 AES-GCM으로 암호화하여 앱 전용 저장소에 보관합니다. 백그라운드 실행을 위해 매 사용 시 생체인증을 요구하는 키는 아닙니다. |
| 사이트 쿠키·웹 저장소·캐시 | 앱 내부 Android System WebView의 로그인과 사이트 동작에 사용합니다. 쿠키는 앱의 사이트 통신과 공유하며 외부 기본 브라우저의 쿠키와 자동 공유하지 않습니다. 사이트 JavaScript와 DOM 저장소는 활성화되어 있고, 제3자 쿠키는 허용하지 않습니다. |
| 근무표·요일·신청 수량·시간·금액 한도·날짜별 예외·동의 상태 | 달력과 자동 신청 계획에 사용하며 앱 전용 SQLite 데이터베이스에 저장합니다. 근무와 휴가 정보도 개인 일정에 해당할 수 있습니다. |
| 실행 날짜·수량·상태·단계·메시지·금액·서버 주문번호·전송 가능성 | 중복 제출 방지와 결과 확인에 사용하며 앱 전용 데이터베이스에 저장합니다. 현재 개별 실행 기록의 자동 만료·일괄 삭제 기능은 없습니다. |
| 알림·초기 설정·알람·백그라운드 점검 상태 | 앱 전용 환경설정에 저장합니다. 재부팅 예약 복원에 필요한 시각·토큰·세대·점검 요약 등 일부 메타데이터는 기기 보호 저장소에 보관합니다. 계정 비밀번호나 사이트 쿠키는 이 메타데이터에 저장하지 않습니다. |

배송지와 수령인 정보는 사이트에서 등록·변경합니다. 앱은 주문 과정에서 사이트가 제공한 값을 처리하지만 독립된 배송지 주소록이나 개발자 서버에 저장하지 않습니다. WebView 화면과 캐시에는 사이트가 제공한 개인정보가 포함될 수 있습니다.

## 외부로 전달하는 정보

- `https://dosirak.poswel.co.kr` 로그인·조회·신청 통신에는 계정, 사이트 세션 쿠키, 신청 날짜·수량과 사이트 주문 양식에 필요한 정보가 전달됩니다. 서버의 실제 주문·공제·보관·취소는 사이트 운영자의 정책을 따릅니다.
- 앱을 열 때와 사용자가 `새 버전 확인`을 누를 때 `https://api.github.com/repos/fullmetalsonic/poswel-dosirak/releases/latest`로 최신 공개 정식 릴리스 정보를 조회합니다. GitHub는 통신상 IP 주소와 요청 시각·User-Agent 등 일반 요청 정보를 받을 수 있습니다. 조회 요청에 사이트 계정·쿠키·주문 데이터·GitHub 토큰을 넣지 않습니다. 배포 페이지를 열면 외부 브라우저와 GitHub의 정책이 적용됩니다.
- 사용자가 외부 링크를 선택하여 브라우저를 열면 해당 사이트와 브라우저의 정책이 적용됩니다. Android System WebView 및 운영체제의 안전 브라우징 등 플랫폼 처리도 각 제공자의 정책을 따릅니다.

앱 자체의 별도 개발자 수집 서버, 광고 SDK, 사용자 분석 SDK 또는 원격 오류 업로드 SDK는 현재 선언된 앱 의존성과 운영 소스에 포함하지 않습니다. 이는 사이트 내부 스크립트·Android·WebView·GitHub의 자체 처리가 없다는 뜻은 아닙니다.

## 진단과 알림

앱의 로컬 Android 진단 로그에는 시각, 이벤트 종류, 허용 경로의 분류, HTTP 메서드, 오류코드와 WebView 버전이 기록될 수 있습니다. 계정·비밀번호·쿠키·POST 본문·전체 URL·조회문자열을 진단 항목에 넣지 않습니다. 진단 로그를 개발자에게 자동 전송하지 않습니다. 사용자가 별도로 로그·스크린샷을 공유할 때는 화면의 개인정보를 확인해야 합니다.

알림에는 신청 상태와 날짜 등 처리 결과가 표시될 수 있습니다. 잠금화면 표시 범위는 Android 알림 설정에서 관리합니다.

## 백업과 삭제

자동 Android 클라우드 백업은 비활성화하며 데이터 추출 규칙에서 클라우드 백업과 기기 이전의 앱 저장 영역을 제외합니다. 기기 제조사·운영체제의 구현과 별도 사용 도구까지 보장하지 않습니다.

`설정 백업 내보내기`는 사용자가 선택한 파일 위치에 설정과 날짜별 예외를 JSON으로 저장합니다. 계정·비밀번호·쿠키·실행 기록은 넣지 않으며 실제구매 승인과 자동주문 활성 상태는 백업에서 해제합니다. 내보낸 파일에는 근무·휴가 등 개인 일정이 포함될 수 있고, 선택한 클라우드 폴더의 동기화 정책은 해당 서비스가 관리합니다.

`설정 → 계정 → 계정 삭제`는 저장 자격증명을 지우고 WebView 쿠키를 삭제하며 실제구매 예약을 해제합니다. 이미 사이트에 보낸 주문, 앱 실행 기록, WebView의 모든 캐시·DOM 저장소까지 지우는 기능은 아닙니다. 쿠키 삭제가 실패하면 앱이 오류를 표시하므로 결과를 확인하세요.

기기 안의 앱 설정·기록·WebView 데이터 전체를 제거하려면 Android 앱 설정의 저장공간에서 앱 데이터를 삭제하거나 앱을 제거합니다. 사용자가 따로 내보낸 백업 파일과 사이트 서버의 주문·개인정보는 이 동작으로 삭제되지 않습니다. 내보낸 파일은 해당 저장 위치에서 별도로 지우고, 사이트 서버 데이터는 사이트 운영자의 절차를 이용합니다. 앱 데이터 초기화 뒤에는 새 주문 전에 사이트 주문내역을 확인하세요.

## 변경과 문의

기능과 처리 범위가 바뀌면 이 문서도 갱신합니다. 앱의 공개 배포와 별개로 사이트 이용약관·자동화 허용 여부·사이트 개인정보 처리방침을 확인해야 합니다. 앱 관련 오류는 [프로젝트 이슈](https://github.com/fullmetalsonic/poswel-dosirak/issues)에서 알릴 수 있으며 공개 이슈에 비밀번호·세션 쿠키·전화번호·배송지·주문 원문을 올리지 마세요.
